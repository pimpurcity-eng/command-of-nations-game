# Air-defense review map

Open game/project.godot in Godot 4.6.3. Open scenes/air_defense_test_map.tscn and run the current scene (F6).

The private owner test ZIP starts directly in this scene when you press Run Project (F5). It includes the original model assets privately; those models remain excluded from Git.

Ten original models: Russian column on the left, European column on the right. The five rows are Strela-10 / Roland; Tor-M2 / NASAMS; Buk-M3 / IRIS-T SLM; S-400 / SAMP/T; S-500 / ASTER 30.

Every cab/hull initially faces seven o'clock relative to the starting camera. This is a review pose, not a forced orientation during movement or combat. Tap either column to control that side. The selected unit shows its actual defense range. Tap Move, choose a destination, and Play to test travel, heading and launcher packing. AI is disabled and the map starts paused.

These review units include late-game equipment so the owner can inspect all ten. Normal research retains S-500 at Day 18. The main campaign still keeps the retired weapons archived.
